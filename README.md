# GREENLINE web page

The public page for GREENLINE, a co-op cube zombie shooter for iPhone and Android by Tufufal Studios.

Everything here is built by a script (`tools/build_site.py` in the greenline-media repo), so please don't edit these files by hand. Changes made here are replaced the next time the page is rebuilt.

The page is plain files: no cookies, no trackers, and nothing loaded from other sites.
